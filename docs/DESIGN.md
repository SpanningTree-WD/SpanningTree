# Spanning Tree Website — Design System

## Direction

Modern Academic Archive

Keywords:

- Academic
- Editorial
- Archival
- Restrained
- Precise
- Calm
- Typography-driven

## Approved Reference

`reference/spanning_tree_sample.html`

This file is the primary visual reference.

New pages should look like they belong to the same website.

## Visual Principles

### Color

Main visual language:

- warm off-white background
- near-black text
- dark muted green accent
- subtle gray-green borders

Avoid excessive use of additional colors.

### Typography

- Serif fonts for major headings and identity
- Clean sans-serif fonts for body and interface text
- Strong hierarchy
- Comfortable long-form reading

### Layout

Prefer:

- clear grids
- thin separators
- generous whitespace
- archive-style lists
- editorial layouts

Avoid excessive cards.

### Activities

Activities may use:

- larger photography
- visual thumbnails
- dates and activity types
- editorial portfolio layouts

### Mathematics

Mathematics should prioritize:

- readability
- title
- author
- field
- type
- year
- mathematical content

It should feel closer to a mathematical journal/library
than a marketing page.

### Avoid

Do not introduce:

- generic SaaS design
- glassmorphism
- neon
- glow
- excessive gradients
- excessive border-radius
- large drop shadows
- decorative math symbols everywhere
- unnecessary animations

## Responsive Design

Desktop, tablet and mobile must all be supported.

Responsive behavior should preserve the information hierarchy,
not merely shrink the desktop layout.
