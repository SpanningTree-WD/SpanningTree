# 구성원과 멘토링

실제 명단과 모임은 `src/content/people.ts`에서 관리합니다. 현재 People 페이지는
이 데이터를 읽으며, 관리자 편집 화면이나 Firestore 연결은 추가하지 않았습니다.

- `peopleGenerations`: 36기 8명, 37기 8명, 38기 7명. 연도와 학년을 추정하지 않습니다.
- `mentoringGroups`: 이산수학·선형대수학·위상수학·해석학·추상대수학의 시간과 멘토/멘티.
- 기수와 멘토링 역할은 별개입니다. 예를 들어 장민준은 36기이며 해석학 멘티입니다.
- 임호준은 36기 명단에 포함되며, 제공되지 않은 멘토링 관계는 추가하지 않습니다.
- 한 모임의 모든 멘토에서 그 모임의 모든 멘티로 선을 연결합니다. 이는 모임 안의
  관계를 표현하며, 특정 멘토/멘티만의 일대일 배정을 의미하지 않습니다.
- 멘토링 연결은 데스크톱·모바일에서 항상 표시합니다. 표시/숨기기 토글은 없습니다.
- 각 구성원은 자신의 기수 층에 한 번만 나타납니다. 36기·37기·38기 세 층을
  유지하고, 같은 모임의 사람이 가까이 놓이도록 가로 위치를 계산합니다.
- 실선은 같은 기수, 과목별 색의 점선 화살표는 멘토 → 멘티 관계입니다.
  같은 층의 관계는 위로 굽은 곡선으로, 높은 층으로 가는 관계는 위쪽 화살표로 표시합니다.
- 이름에 마우스를 올리거나 키보드 초점을 두면 해당 연결선만 굵어집니다.
  나머지 관계도 계속 보이며, 별도 과목별 사람 목록이나 표시/숨기기 토글은 없습니다.
- 작은 화면에서도 층 구조를 유지하고 그래프 영역 안에서 좌우로 스크롤합니다.
  그래프 아래 범례에 과목과 시간을 표시하고, 보조 기술용 관계 설명도 제공합니다.

`src/features/people/graphLayout.ts`가 노드 배치와 연결 경로를 계산하고,
`MentoringGraph.tsx`가 SVG로 표시합니다. 외부 그래프 라이브러리는 사용하지 않습니다.

명단을 바꿀 때는 중복 이름이나 누락된 기수가 없는지, 모임의 모든 이름이 기수별
명단에 존재하는지 확인하세요. 같은 이름의 구성원이 추가되면 고유 ID 기반으로
확장해야 합니다.
