# 자료 검색·정렬·필터

- 헤더 돋보기는 `/search` 통합 검색으로 연결됩니다. 활동·수학 자료·출판물 중
  공개된 글만 검색하며 자료 종류로 좁힐 수 있습니다.
- 각 자료 목록에도 검색창과 최신순·오래된순·제목순 선택이 있습니다.
  활동은 활동 날짜, 수학 자료·출판물은 연도를 기준으로 정렬합니다.
  날짜/연도가 같으면 수정 시각을 비교하고, 동일한 경우 제목·ID로 순서를 고정합니다.
- 제목순은 한국어 로케일과 자연수 순서(`정리 2` → `정리 10`)를 사용합니다.
- 제목·요약·본문·작성자·편집자·태그·분류·연도를 검색합니다. 영문 대소문자를
  구분하지 않고, 여러 단어는 모두 포함된 글을 찾습니다. 분류의 한글 이름도
  검색됩니다. PDF 내부 텍스트를 추출하거나 외부 첨부 파일을 검색하지는 않습니다.
- `q`, `sort`, `year`, `type`, `field`를 URL에 보관합니다. 통합 검색은 자료 종류에
  `kind`를 사용합니다. 새로고침·뒤로/앞으로 가기·링크 공유 시 조건이 유지됩니다.
  검색어 초기화는 필터·정렬을 유지하고, 필터 초기화는 검색어·정렬을 유지합니다.
- 연도 선택지는 실제 공개된 자료에서 생성합니다. 비공개 글의 연도와 분류는
  노출되지 않습니다. 분류는 `src/models/contentOptions.ts`의 관리자 공통 목록과
  기존 공개 자료의 분류를 합칩니다. 검색 결과가 0개여도 선택지는 사라지지 않습니다.
- 980px 이하에서는 `필터 열기`로 펼치며 선택 후에도 펼친 상태를 유지합니다.
  닫힌 상태에서도 적용된 조건과 초기화 버튼이 보입니다. 모바일에서도 헤더 검색이 보입니다.

## 구현 위치와 검증

- `src/repositories/archiveQuery.ts`: 로컬/Firebase가 공유하는 검색·정렬·필터·선택지 계산.
- `src/features/shared/useArchiveResults.ts`: 목록 진입 시 공개 자료를 한 번 읽고
  같은 데이터에서 조건을 적용합니다. 필터 클릭마다 Firestore를 다시 읽지 않습니다.
- `src/repositories/searchRepository.ts`: 세 공개 저장소의 결과를 모읍니다.
- `src/features/shared/useArchiveControls.ts`: URL 상태와 초기화 처리.
- `src/components/archive/`: 공통 검색창·정렬 선택·반응형 필터.

현재 저장소의 공개 자료 전체 조회 구조를 유지합니다. 서버 페이지 구분, 검색 엔진,
PDF 전문 검색은 이 변경에 포함되지 않습니다. 자료량이 커질 때 별도 개선합니다.

`npm test`는 정렬 순서, 검색·필터 조합, 비공개 자료 제외, 새 연도와 기존 분류,
URL 복원, 모바일 필터 펼침 상태, 통합 검색을 검증합니다. 화면 크기에 따른
필터 표시와 헤더 배치는 브라우저에서 별도로 확인합니다.
